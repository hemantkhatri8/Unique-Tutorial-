🔗 Connect to Google Sheets

Follow these steps once. After setup, all student data is saved permanently in your own Google Sheet.

1Open sheets.google.com → create a new sheet → name it UniqueTutorial.
2In that sheet, click Extensions → Apps Script. Delete everything and paste the code from the appsscript.js file provided. Click 💾 Save, then click ▶ Deploy → New Deployment → Web App. Set "Who has access" to Anyone. Copy the Web App URL.
3Paste the Web App URL below and click Save & Test.
